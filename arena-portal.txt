3. PAGE-BY-PAGE BREAKDOWN
-----------------------------------------------------------------------------

PAGE 1: CHATBOX (/) ★ PRIMARY FEATURE
  Purpose: ChatGPT-style AI chat interface — the CORE of the arena portal
  Route: / (default landing page)
  Layout: Split-screen (chat thread + output panel)
  Components:
    - ChatThread: Scrollable message list with AI/user bubbles
      * AI messages: glass-panel background, left-aligned
      * User messages: cyan gradient background, right-aligned
      * Typing indicator: bouncing dots animation
    - ChatInput: Textarea with auto-resize
      * Paperclip button: Upload PDF (future)
      * Image button: Upload image (future)
      * Send button: cyan-to-purple gradient
    - QuickActionChips: Shown on first load (when ≤1 message)
      * "Architect my Capstone Project" → Document output (PDF)
      * "Draft Panchayat Notice to Excel" → Spreadsheet output (XLSX)
      * "Create a PPT on AI in Education" → Presentation output (PPTX)
      * "Generate Instagram Content Strategy" → Image output
      * "Write Python script for data analysis" → Code output
    - OutputPanel: Right-side split panel (desktop) ★ SINGLE UNIFIED PANEL
      * Adapts to output type automatically (no tabs)
      * Shows live preview of generated content
      * Action bar: Download + Copy Code buttons
      * Empty state: "No output yet" placeholder
      * Collapsible: "Show Output" / "Hide Output" toggle
      * Mobile: Full-screen modal overlay
  Output Types (5):
    - Document: Rendered text with headings, paragraphs, formatting
      * Preview: White page with formatted content (mini-Word doc)
      * Download: PDF via jsPDF
    - Spreadsheet: Interactive table grid
      * Preview: Scrollable columns/rows, header row highlighted cyan
      * Download: XLSX via SheetJS
    - Presentation: Slide cards with gradient backgrounds
      * Preview: Slide thumbnails, staggered reveal animation (Gamma-style)
      * Animation: Slides appear one by one, 500ms apart, fade+slide
      * Download: PPTX via PptxGenJS
    - Image: Image tile grid
      * Preview: 2x2 or 3x2 tile grid with gradient backgrounds
      * Download: PNG via Canvas API
    - Code: Syntax-highlighted code block
      * Preview: Mono font, line numbers, language badge
      * Download: .py / .js / etc. file
      * Copy: Copy code to clipboard
  State Variables:
    - messages: array [{ role: 'ai'|'user', text: string, isConfirm?: boolean }]
    - input: string
    - panelOpen: boolean (output panel visibility)
    - mobilePanelOpen: boolean (mobile panel overlay)
    - currentOutput: { type, content } | null (active output)
    - typing: boolean (AI typing indicator)
    - pendingConfirm: { confirmType, prompt } | null (waiting for user confirmation)
  Two-Phase Confirmation Flow:
    Phase 1 (Confirm): User requests document → AI asks "Should I generate?"
      * AI returns: { text: "message", type: "confirm", confirmType: "doc", prompt: "original request" }
      * ChatBox renders ConfirmationCard with "Yes, generate" / "No, thanks" buttons
      * Output panel stays hidden
    Phase 2 (Generate): User clicks "Yes, generate" → AI generates content
      * API call with mode: 'generate' → AI returns full content
      * ChatBox renders Output panel with preview
      * Output panel slides open automatically
    Normal Chat: User asks question → AI responds with text only
      * AI returns: { text: "response", type: null, content: null }
      * Just shows text in chat. No Output panel.
    Quick Action Chips: Skip confirmation, go directly to generation
      * Chip click → send(text, { skipConfirm: true })
      * API call with mode: 'generate' → AI generates content immediately
  ConfirmationCard Component:
    - Glass panel with cyan border glow
    - Shows AI's confirmation message
    - "Yes, generate" button: cyan-to-purple gradient
    - "No, thanks" button: muted border
    - Appears below the last AI message
  AI Reply Structure:
    - Each reply includes: text (displayed in chat) + type + content (for output panel)
    - type: 'doc' | 'data' | 'ppt' | 'image' | 'code' | null
    - content: Type-specific data (sections, columns, slides, tiles, code)
  Download Libraries (client-side, zero server cost):
    - jsPDF (90KB) — PDF generation
    - SheetJS/xlsx (350KB) — XLSX generation
    - PptxGenJS (200KB) — PPTX generation
    - Canvas API (0KB) — PNG generation
    - Total bundle: ~640KB (gzipped ~200KB)
  Cost per document: ~₹0.02 (AI API call only, file generation is free)

  - Share card generation: Flip animation + download trigger
  - Timer countdown: Color transitions (green -> yellow -> red)
